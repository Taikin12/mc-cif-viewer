# Sample CIF files

These files are small test structures for the viewer. They are not a critically
evaluated structure database.

## Hand-prepared samples

The following files are conventional cells prepared from standard crystal
structure data for testing:

- `NaCl.cif`
- `diamond-C.cif`
- `graphite-C.cif`
- `MgO.cif`
- `TiO2-rutile.cif`
- `SrTiO3.cif`
- `ZnO-wurtzite.cif`
- `Fe-bcc.cif`
- `CaF2-fluorite.cif`

No copyright is claimed for these structure data.

## Crystallography Open Database (COD)

The following files are derived from COD entries:

- `TiO2-anatase.cif` — COD 9008213
  - Horn, M.; Schwerdtfeger, C. F.; Meagher, E. P.
  - "Refinement of the structure of anatase at several temperatures",
    Zeitschrift fur Kristallographie 136 (1972) 273-281.
  - https://www.crystallography.net/cod/9008213.html
- `TiO2-brookite.cif` — COD 9009087
  - Wyckoff, R. W. G., Crystal Structures, 2nd ed., Vol. 1, 1963, pp. 239-444.
  - https://www.crystallography.net/cod/9009087.html

COD data and the database itself are dedicated to the public domain under the
CC0 license. Users of the data should acknowledge the original authors of the
structural data.
